# 闲鱼虚拟商品主图

主图的任务只有一个：在搜索结果那一小格里，让买家一眼看懂"这是什么、有多少、怎么拿"，然后点进来。它不是海报设计，信息要大、要少、要准。

规律来自闲鱼搜索里排名靠前的虚拟资料链接，以及三家对标店的热门 30 件，见 `references/patterns.md`。

## 流程

1. **拿到素材**：商品文案（通常是 listing-copy-mimic 刚写好的标题、正文），以及网盘里的真实文件清单。图上每个字、每个数字都要能在这两样里找到出处。
2. **选版式**，见下表。
3. **写 spec**：一个 JSON 文件，放在用户工作区的 `xianyu-assets/` 下（没有就新建），文件名用英文，比如 `yixue-main.json`。
4. **渲染**：
   ```bash
   python3 ~/.claude/skills/xianyu-main-image/scripts/render.py xianyu-assets/yixue-main.json xianyu-assets/yixue-main.png
   ```
   会得到三个文件：`.png`（上传用）、`.thumb.png`（缩小版，模拟搜索列表里的效果）、`.html`（可编辑源文件）。只需要 Google Chrome，不需要装 Python 包。
5. **自己先看**：读 png 和 thumb.png。缩小版里三个大字还认得出、没有文字压线或溢出，才算过关。不过关就改 spec 再渲染，不要把有问题的图交出去。
6. **交付**：把 png 发给用户，说清楚图上哪些数字需要用户确认。

## 选版式

| 版式 | layout | 适合 | 样例里的样子 |
|---|---|---|---|
| 内页压字 | `overlay` | 资料、讲义、知识点、真题、单词表：有一页「一看就是干货」的内页 | 对标店最常见：一页真实内页铺满，中间压两条粗字条「高中物理知识点总结」「必修123+选择性必修123」 |
| 大字报 | `poster` | 资料合集、课程合集，有 2–3 个响亮的主题词 | "曾仕强全集""傅佩荣全集"：名字超大，下面一串卖点 |
| 目录清单 | `catalog` | 内容多、种类杂，每项都有数量可写 | "曾仕强讲座全集"：01–10 编号目录，每行带套数 |
| 工具封面 | `cover` | AI 工具、Skill、手册、SOP | "AI一人公司全流程搭建手册""贴图养号SOP"：白底大黑字 + 01/02/03 |
| 预览拼图 | `preview` | 模板、素材、练习纸，"长什么样"就是卖点 | "苏州大学PPT 32套"：真实页面拼图 + 大数量 |

**资料、讲义、真题类默认用内页压字（overlay）**：2026-11-17 看三家对标店热门 30 件，23 件主图是真实内容打底，其中 16 件就是「一页内页铺满 + 中间压 1–3 条粗字条」；24 件是竖图。只有 1 页像样的截图也能做，所以它是资料类的首选。

- 挑哪一页：选**信息密、有颜色、一眼像干货**的页，比如目录、带标注的知识点页、表格页。封面页反而不好，看不到货。
- 字条写什么：第一条写品名（学段 + 科目 + 类型，6–9 字）；第二条写一个具体卖点，比如页数、版本（背诵版+默写版、原卷版+解析版）或内容组合（知识点+易错题+口诀）。有确定的页数可以放进 `tag`。
- 字条一般两条就够，对标店多数也是两条。第三条只在很短、又真的是卖点时加；浅色页面上不要用白底字条，会和页面糊在一起。
- 主图只放卖点。「老教材」「图片版不能复制」这类提醒写在正文和交付卡里，不要上主图。
- 主图用的那一页，不要再当第一张配图，否则买家翻到第二张看到的还是同一页。
- 模板、素材、练习纸这类「长什么样就是卖点」、手上有 4 张以上截图的，用预览拼图（preview），`count` 写真实数量或年份区间。

内页压字和预览拼图都必须用**用户自己的资料截图**。别人链接里的宣传图不能用：闲鱼有反向搜图，会被判盗图。没有截图就换别的版式，并告诉用户截几页发来效果会更好。

同一个店的几条链接，版式和主题色也要换着用，原因和文案一样：满屏一个样子既让买家疲劳，也可能被判重复铺货。

## spec 字段

通用：`layout`、`theme`，可选 `colors`（覆盖主题里的某个颜色）、`size`（`"3:4"` 出 1080×1440 竖图，`"1:1"` 出 1080×1080）。overlay 默认 3:4，其他版式默认 1:1。资料类用别的版式时，也建议加 `"size": "3:4"`，不过那几个版式是按方图排的，换成竖图后要看一眼渲染结果。

主题 `theme`：
- `ink-gold`：墨蓝配金，适合国学、古籍、易学
- `red-gold`：红配金，喜庆醒目，适合考试、合集
- `blue-white`：蓝白，适合教育、考证
- `kids-yellow`：暖黄橙，适合幼儿、亲子
- `fresh-green`：清新绿，适合生活、兴趣
- `tech-white` / `tech-dark`：适合 AI、工具、Skill

| layout | 字段 |
|---|---|
| overlay | `images` 一张内页截图；`bands` 1–3 条字条（第一条最大）；可选 `tag`（红色圆角标，比如 "143页"）、`bottom` 底部交付条、`bandsTop` 字条起始高度（0–1，默认 0.36）、`align` 截图对齐（top/center）、`veil` 白色蒙层透明度（截图太花时用 0.15–0.3）、`tilt` 字条倾斜角度、`bandColors` 字条配色 |
| poster | `kicker` 顶部一行；`big` 主题词数组（一行 2–3 个，如 `["易经","风水","六爻"]`；两行写成二维数组）；`ribbon` 红条卖点；`chips` 门类格子（最多 8 个）；`note` 一行补充；`bottom` 底部横幅；可选 `seal`（四字印章）、`badge`（左上角标）、`deco: "bagua"`、`frame: false` |
| catalog | `kicker`；`title` 大标题；`ribbon`；`list` 目录，每项写成 `["名称","数量"]`，最多 10 项；`bottom`；可选 `seal`、`badge` |
| cover | `kicker` 左上标签；`titleLines` 标题分行；`highlight` 要变色的行号（如 `[1]`）；`tag` 一句话；`steps` 2–4 条；`bottom`；可选 `icon`（一个 emoji） |
| preview | `images` 截图路径（相对 spec 文件，4 或 6、9 张最好）；`count` 大数量（如 "32套"）；`title`；`subtitle`；可选 `badge` |

`examples/` 里每种版式各有一份 spec 和渲染结果，照着改最快（内页压字见 `overlay.json`，把 images 换成你自己资料的真实页面）。

## 写图上文字的规矩

- **字少、字大**：主题词 2–3 个，每个 2–4 字。搜索列表里一格只有手指那么宽，小字等于没有。
- **数字是钩子，但必须真实**：容量（35G）、套数、集数、页数、题数，这些是样例里最常见的卖点。只写资料里能核实的；来自文件夹名、没核实过的数字，交付时提醒用户确认。
- **交付方式上图**：底部一句"电子资料 · 拍下后闲鱼内发网盘链接"。样例几乎都有，能提前挡掉以为是实物的买家。
- **不放人像、品牌标志和 IP 形象**：样例里很多把讲师照片放上去，但那是肖像权和版权投诉的重灾区。动画角色、出版社封面、学校校徽同理。
- **不放二维码、微信号、手机号**：会被判站外引流。
- **不用极限词**：最全、第一、全网最低这些在主图上同样违规，和文案用同一套规矩。
- **和文案对得上**：主图的大字和文案的核心词、数字保持一致，买家点进来不会觉得货不对板。

## 配图（第 2–9 张，每个商品都要）

对标店热门商品的配图中位数是 8 张，大多是真实内页。买家翻配图是在确认「货是不是真的、够不够多、是不是我要的那个年级/版本」，所以配图要多、要真。

推荐顺序（总共 6–8 张，按货的多少增减）：
1. **目录页**一张：让人一眼看到有多少章、多少页。
2. **代表性内页** 3–5 张：每张一页，铺满，不缩成小图。一个包里有几份文件的，每份至少放一页。有版本区分的（背诵版/默写版、原卷/解析），可以在页角压一个小标签。
3. **网盘目录截图** 0–1 张：文件多、种类杂时放一张，证明「一共有这些」。
4. **交付说明卡**一张，放最后。它是买家下单前看的最后一张，要像「货的说明书」，不能是一页 PPT 文字清单。要求：
   - **和主图同一套配色**（主图用了什么字带颜色，这张就沿用），不要另起一套通用浅蓝。
   - **把货摆出来**：3–4 张真实内页缩略图叠放或并排，旁边一张文件卡：文件类型色块（Word/PDF）、真实文件名、页数和大小。多文件的包就列文件名清单。
   - **交付流程一行三步**，带箭头：拍下 → 闲鱼自动发网盘链接 → 转存或下载。
   - **卖点 2–3 条**，小字，数字和正文一致。
   - **提醒类（老教材、图片版不能复制等）只放最下面一行小字**，不要做成大号要点，否则像在劝退。
   - **画面填满**，不留大片空白；尺寸和其他配图一致。
   - 做完和主图放在一起看一眼：像同一家店出的才算过。

截图的规矩：
- 只用用户自己网盘里、检查过的文件。同行的配图不能用，原因同上。
- 页面里有别人的水印、二维码、联系方式、品牌标志，这页就不用，换一页，不要涂抹后再用。
- 截网盘目录时，**从分享链接页截**（pan.quark.cn/s/…），不要从自己的网盘后台截，分享页更干净。截之前把页面放大（比如 `document.body.style.zoom='1.7'`）；只截文件列表，裁掉头像、用户名、分享者信息和广告。
- 存到商品文件夹的 `shots/` 下，转成宽 750 像素的 jpg 再上传（易店建议的最大宽度）。
- 不要用 AI 重画页面或文件名，截图必须是真实的。

## 修改

用户要改字、改色、换版式时，改 spec 再渲染一次就行。要做模板里没有的效果，可以直接改同名的 `.html` 源文件，再用 Chrome 打开截图。
