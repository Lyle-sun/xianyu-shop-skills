# 选品渠道：去哪看需求、去哪找货

选品分两步：先看**什么好卖**（需求），再去**找货**（货源）。两步的结果都记下来，下次先查记录再动手。

## 一、看需求（按可信度从高到低）

| 来源 | 在哪 | 怎么用 |
|---|---|---|
| 对标店在售商品 | 配置 `BENCHMARK_SHOPS`；抓下来的列表在 `research/benchmark/<日期>/pool.csv`（列：shop、title、price、want…） | 按 `want`（想要数）排序，挑想要数高、我们还没查过的方向；同方向记 1–2 个对标链接 |
| 本店在售数据 | `shop.sh stats`、`data/` 下的快照 | 自己的浏览/想要是最直接的证据 |
| 闲鱼官方榜单（缺货榜、求购） | 知识库「官方榜单」 | 买家求购、平台缺货 |
| 闲鱼搜索 | 闲鱼 App/网页 | **只搜店主给的词，只看 1 页**，碰到风控就停；排名由店主自己看 |
| 需求日历 | 知识库「2027中国全年关键事件与需求日历」 | 做下个月和下下个月的节点（考试、开学、节日），提前 1–2 个月上 |

对标里一条都没有的方向（比如油管、抖音运营文档），说明对标店不做这个品类，不能当作「有需求」的证据，报告里照实写。

## 二、找货（公开分享，只读）

| 渠道 | 地址 | 特点 |
|---|---|---|
| 盘行（主力） | panhang.com | 详情页 `/doc/<id>` 能取到夸克直链；搜索页是前端渲染，要用无头 Chrome 打开；**不登录只能看第 1 页**（翻页要登录，就停）；高频会触发 IP 限流，停一会儿再查，不绕 |
| pansearch | pansearch.me | 结果杂，按时间排，翻页参数常失效；当补充 |
| 夸克小站 | www.pioz.cn | 夸克资源聚合搜索；品类少，冷门方向常 0 条 |
| 资源星球（资源星图） | resources.examcalenders.com；本地索引 `research/benchmark/1117/.work/resource-items.json`（4,718 条） | 先在本地索引按关键词筛，再去站上取链接 |
| 本地货源表 | `data/huoyuan-items.json`（707 条） | 以 K12、简历、PPT、表格为主 |
| B 站动态正文 / 公开文章 | 搜「关键词 + 夸克」 | 偶尔能翻出夸克链接；公众号文章常要验证，遇到就换站 |
| panlama 资源库 | https://panlama.com/resources | 网盘资源合集，可直接转存 |
| X 上的资源号 | X（推特）上分享网盘资源的账号 | 资源多，帖子里直接给网盘链接；只看公开帖，不登录、不私信 |
| 公众号搜索 | 微信搜一搜 | 常弹「环境异常」验证，遇到就换站，不过验证码 |
| 腾讯文档·百度网盘资料库 | https://docs.qq.com/sheet/DS1VnS1Jwb3VsUmpD?tab=000002 | 百度网盘链接，**不能直接转存到夸克**：要先下载再传夸克，体积大的先问店主 |
| Z-Library | https://zh.z-lib.fm | 电子书、学术文献；没有现成网盘分享，要下载再自己传，单本小，要按主题拼够 500MB；体积大的先问店主 |
| 拼多多、淘宝资料店 VIP | 搜「资料店铺 VIP」 | 9.9–19.9 元开店铺 VIP 下载整理好的资源。**要付钱，agent 不买，只记店名、价格、能拿到什么，由店主自己买**；先在上面免费渠道找，实在没有再走这条 |
| 飞书货源清单 | https://ocnqfwcokvma.feishu.cn/docx/V6vUdRRNFoMBfexUu3AcAXBlnMh | 店主收集的渠道总表，上面各条都出自这里 |

- **不用**：吾爱破解、果核剥壳这类破解软件站（破解在红线里）。
- 夸克链接只认 `pan.quark.cn`，仿冒域名（quarkk.xyz 等）不点。
- 夸克匿名接口能看目录、文件大小、首页预览（`sharepage/token` + `detail` + `file/info`），匿名下载常被拒；**抽查就看首页预览和文件名**，不为抽查转存。
- 盘行标的大小常不准，以夸克实际遍历为准。
- 每条候选从公开分享看 3–5 个小文件的首页预览，记有没有引流件（加微信、扫码、网盘小程序图）、破解软件、时效。

## 三、找货的口径

- 每个方向 2–4 个关键词，最多记 3 条候选：名称 | 渠道 | 链接 | 有效否 | 总大小 | 结构（层数/文件数）| 最新年份 | 抽查结果 | 判断。
- 判断只有：**可上** / **可上待拼**（写清拼法、拼完多大）/ **不碰**（写原因）/ **没找到**。
- 按 `redlines.md` 判：500MB、两层、≥20 文件、时效（按买家下一次要用的年份）、不碰的品类。

## 四、记在哪

- 报告：`research/sourcing-<MMDD>-<方向>.md`，开头先写「结论」几条；同步一份到知识库本账号「选品报告」目录（见 `templates/_rules.md`）。
- 线索：飞书「线索库」表，**先查重再写**，一品一行，「账号」列填本店标记。判过「不能上」的下次不再查。
- 写不进飞书（登录/权限报错）就把报错原文和待写清单写在报告里，不绕。

## 五、实战经验（2026-11-22/23，一晚派 25 个品后总结）

- **找货阶段就抽帧，不留到转存。** 课程类每条在报告里就看封面帧 + 中间帧（匿名接口拿不到中间帧的，判「可上待拼」，转存前必须补抽）。烧着网址/微信/QQ/机构或讲师水印的直接判不碰：这一晚 25 个品里 13 个是转存后才停，全白干。常见的：猫窝 maowotao/maomp.fun、x6d.com、you85.com（中创网）、zx-cc.net（自学成才网）、知乎知学堂、集智、尚硅谷 atguigu、黑马 itheima、迪哥讲堂、雷神训练营。
- **PSD/素材也要看元数据和图层。** 文本层、XMP 版权字段里带付费素材站域名（888pic、lfx20、nicepsd 等）、图里有学校校徽校名的，整包不碰。素材文件名 100% 带公众号/店铺名的整包弃。
- **命中率参考**：素材类（音效、视频素材、笔刷、免抠 PNG、PSD 模板）最高；文档/提示词/模板次之；视频课最低（10 门 AI 课只过了 1 门）。凑数量时优先素材和文档。
- **对标店里没有的品类只算试水**：先上 2–3 个不重复的，跑几天看浏览/想要再决定加不加；不要同一件货换标题铺多个链接（同行这么做，我们不学：重复铺货会被限流扣分）。
- **iOS 降级/越狱、激活锁绕过、刷机工具这类不做**：属于破解，教程里夹着工具也不行。
- **副业类标题**不写收益承诺（月入、日赚、躺赚、零成本、保底）和无货源/引流/搬运/去重，只写清是什么资料。
