# 品类标签

每件货（在售商品、线索库里的线索、新建的商品）都打同一套标签，店主才能按品类比数据、做品类测试。

存放：
- 在售商品：`$SHOP_DIR/data/catalog.json`，按易店商品 ID（goods_id）为键。
- 新建商品：`xianyu-assets/<代号>/tags.json`，上架后由发布角色合并进 catalog.json。
- 线索库：飞书线索库表里同名的几列（有配置时）。

## 字段

| 字段 | 填什么 | 取值 |
|---|---|---|
| `category` | 大类 | 下表 7 选 1 |
| `sub` | 细分：学段+科目，或主题 | 自由写，越短越好：`小学数学`、`高中物理`、`考研政治`、`公众号运营`、`PPT模板` |
| `stage` | 学段（只有 K12/考试/语言需要） | `学前` `小学` `初中` `高中` `大学` `成人` `不分` |
| `year` | 资料年份 | 四位年份；看不出来写 `null` |
| `edition` | 新旧 | `新版`（按现行教材/今年考纲）、`老教材`（旧课标、旧考纲）、`通用`（不分版本，如口诀、模板） |
| `format` | 交付格式 | `PDF` `Word` `PPT` `视频` `音频` `图片` `混合` `其他` |
| `source_shop` | 从哪个对标店选来的 | 对标店名；不是从对标店来的写 `其他` |
| `basis` | 判断依据 | 一句话：看了标题 / 文件 / check.md 的哪条 |
| `confidence` | 把握 | `高`（看过文件）、`中`（看过本地成品）、`低`（只看了标题） |

## 大类

| 大类 | 包括 |
|---|---|
| K12 | 学前到高中的同步资料、知识点、试卷、练习 |
| 考试 | 考研、考公、教资、四六级、职业资格等升学和证书考试 |
| 语言 | 英语启蒙、自然拼读、单词、口语等不绑考试的语言学习 |
| 职场自媒体 | 运营、短视频、直播、办公技能、求职、副业、职业技能培训；**功能型办公文档模板**（合同、简历、成绩分析表等） |
| AI工具 | AI 教程、提示词、Skill、AI 软件 |
| 设计素材 | **视觉类**素材：PPT 模板、海报、图库、图标、字体、字效 |
| 生活通识 | 育儿、健康运动、兴趣、通识读物以外的生活类 |

拿不准放哪类时：按买家是谁、拿去干什么来定（家长给孩子买 → K12；拿去上班干活的文档模板 → 职场自媒体；拿去做视觉设计 → 设计素材）。只有一两件、哪类都不贴的，先放生活通识，攒到 5 件以上再考虑开新类。

## 例子

```json
"1099118903089": {"title":"高中数学知识点归纳汇总105页必修1-5选修Word电子版","category":"K12","sub":"高中数学","stage":"高中",
  "year":2012,"edition":"老教材","format":"Word","source_shop":"对标店A","basis":"check.md：老人教A版必修1-5，2012创建","confidence":"高"}
```
