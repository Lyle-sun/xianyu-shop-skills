# 闲鱼虚拟资料/工具上架文案

这套写法总结自 4 条真实的闲鱼爆款链接，逐字原文都在 `references/` 里（见文末）。下笔前，先读一条和当前商品最接近的样例，找找语感。规则只能告诉你"该有什么"，样例才能告诉你"读起来是什么味道"。

## 核心思路

买家在闲鱼看虚拟商品，心里只有几个问题：**这是什么？能帮我干什么？适合我吗？怎么拿到、怎么用？能退吗？** 好文案就是按这个顺序，每块回答一个问题，不说多余的话。

另外，闲鱼的标题很短，搜索也会读正文，所以**正文开头还有一个任务：补关键词**。

## 一、标题

一整行关键词，没有标点和空格，名词往上堆。每个词都是一个搜索入口。

| 样例 | 标题 | 结构 |
|---|---|---|
| 1 | 2026新版青春期叛逆厌学沟通音视频课全套电子教程 | 年份新版 + 人群 + 痛点 + 形式 + 全套 |
| 2 | 2026全新AI教学神器合集 | 年份全新 + 领域 + 夸张名词 + 合集 |
| 3 | 自动剪辑Skill口播视频一键剪辑AI | 功能 + 形式 + 场景 + 卖点词 |
| 4 | 备课匠skill蒸书多书整合教案出题课件可复制本地离线包 | 产品名 + 形式 + 功能×N + 卖点 + 形式 |

写法：
- 长度：资料包，尤其是 K12、考试类，默认写到 25–30 字，把年级、版本、数量、格式都放进去。对标店热门 30 件里，21 件在 25 字以上，K12 在列表里显示的 30 个字几乎都写满了（见 `references/benchmark-1117-titles.md`）；每多一个词就多一个搜索入口。工具类功能少的，13–20 字说清楚就行。
- K12 / 考试资料可以按这个顺序往上堆词：年份或新版 → 地区或教材版本 → 年级或考试 → 科目 → 内容类型 → 数量 → 版本形式（背诵版+默写版、原卷版+解析版）→ 格式（PDF、word、电子版）→ 用途（复习、提分、备考）。不是每项都要有，资料里没有的就跳过；但顺序保持住，读起来就像买家搜的那串词。
- 年份能让资料显得新，样例1、2都用了"〔年份〕新版/全新"。但年份要按资料的实际年份写（文件名里有"2026下""2027版"这类才写）；看不出年份就不写，不要硬套当前年份。年份写错了，会被买家当成货不对板。也要留意时效：比如考试资料，这一期考试已经考完了，年份反而会劝退买家。
- 年份默认放在核心词后面（比如"教资笔试2026下…"），只有核心词很短时才放开头，免得把核心词挤出前 10 个字。工具类一般以功能或产品名开头。每年换版的教辅（新版教材、新一届中高考）例外：「2026新版」放开头本身就是买点，对标店里有 5 条这么写。
- 结尾落在"是什么东西"上：合集、全套、电子教程、离线包、工具。
- 教材版本词（人教版、苏教版、北师大版……）是很强的搜索词，但要和资料对得上。资料是老教材、而现在在校学生可能已经换了新教材时，版本词不要放在标题开头，免得新教材的家长买错；正文里写清是哪一版、请家长对一下单元。
- 用买家会搜的词，而不是卖家自夸的词。卖 PPT 模板写"答辩汇报述职"，不写"精美高端"。
- 核心品类词尽量放在前 10 个字里，标题在列表里被截断时，最重要的词还看得见。
- 成长、沟通这类非考试资料，也可以用一句话钩子当标题（比如「你必须尽早锻炼与人冲突的能力」），靠推荐流和主图吸引点击。代价是几乎没有搜索词，所以正文开头要把关键词补回来。这种写法目前只在一家对标店见过，用户要求或者商品明显适合时再用。
- 同一个词在标题里只出现一次，不塞和商品无关的热词。重复堆词、跨品类蹭词，闲鱼会判定为关键词堆砌并限流。同一个意思换不同叫法（比如"磨耳朵""英语启蒙"）是可以的，这正好多覆盖一种搜法。

## 二、正文

### 开头：补关键词（4 条样例全都有）

正文第一行重复标题，或者写一个更长、词更多的版本。样例3就是把标题扩成了"自动剪辑Skill口播视频一键粗剪字幕AI智能全流程剪辑工具"。没放进标题的搜索词，就塞进这一行，或者自然地写进后面的"是什么""涵盖…"里，不要单独列一行关键词清单。那样读起来像垃圾广告，买家一看就出戏。

### 主体：按买家的问题排

| 块 | 回答 | 常见写法（引自样例） |
|---|---|---|
| 是什么 | 一句话定位 | 专为〔人群〕打造的〔形式〕，涵盖〔A〕、〔B〕、〔C〕等超全电子资料！<br>〔年份〕年全新整理的〔品质〕〔形式〕，专治〔人群〕〔痛点〕、〔痛点〕、〔痛点〕。<br>〔产品名〕是什么？一套〔形式〕：〔步骤〕 → 〔步骤〕 → 〔步骤〕，一次走完。 |
| 能帮你做什么 | 内容/功能清单 | 重点解决以下5大问题：<br>【6 大核心剪辑环节】<br>能帮你做什么？ |
| 打消顾虑 | 先替买家否定担心的事 | 不联网、不买 Key、不发到任何服务器。<br>无需逐帧手动剪辑 / 无需从头重复 / 无需专业剪辑软件基础 |
| 适合谁 | 3–4 类人群 | 适合老师、教研员、教育从业者… <br>专为二创博主、知识创作者、短视频从业者打造 |
| 怎么拿/怎么用 | 交付方式和上手步骤 | 拍下秒发度盘发<br>怎么用？三步装好 |
| 售后 | 不退 | 见下方"结尾" |

不是每块都要单独成段。资料包很短时，"是什么"和"适合谁"常常合成一句（样例1："专治青少年叛逆、厌学、难沟通"）。

### 清单的写法

条目格式有好几种，四条样例里各用各的：
- **问题清单**：`1、解决〔A〕/〔B〕/〔C〕问题`，读起来像一张疗效清单（样例1）。适合真有焦虑痛点的商品。
- **内容/功能清单**：`- 〔分类名〕：〔具体内容〕`，比如 `- 原版动画：1000集启蒙动画 + English Singsing`（样例3、4的格式，资料包同样适用）。直接把货摆出来，数字、集数、容量都能写进去，比空讲"解决"更可信。
- **一句话涵盖**：不列清单，用一句"涵盖〔A〕、〔B〕、〔C〕等超全电子资料！"带过（样例2）。适合短文案。
- **流程**：用箭头串起来，`粗剪 → 字幕 → 设计 → 动效 → 预览 → 成片`（样例3、4）。适合工具。

**一个店里的链接不要都用同一种。** 满屏"解决…问题"会显得模板化，让买家疲劳；同一个账号发的商品标题和描述高度雷同，闲鱼还会判为重复铺货，降低曝光。四条样例的骨架相同，但开头句、清单格式、结尾各不一样。用户连续写多个商品，或者提到店里已有的文案时，就换着用：这条用问题清单，下一条用内容清单，再下一条用一句话涵盖；开头句也在"专治…""专为…打造""〔名〕是什么？"之间轮换。拿不准时，优先用内容清单，因为货本身最有说服力。

店里发过什么，记在 `shop-log.md` 里：用 xianyu-shop 的，放在店铺目录（配置里的 `SHOP_DIR`）下；没有店铺目录时才用 skill 目录下的那份。放店铺目录是为了让在沙箱里跑的 agent 也能写。**动笔前先读它**，开头句、清单格式、结尾说法尽量避开最近几条已经用过的组合。它是用来避开撞脸的，不是范文：里面的句子不要照搬；**写完后追加一行**，状态记为"草稿"。用户说上架了或下架了，就更新状态。没有这份记录，换一个对话就不知道店里已经有什么了。

但轮换只在**适合这个商品的写法**之间进行，不能为了不一样就换成不合适的写法。先选最适合的格式，再在措辞、顺序、开头句上做区分。同一个商品要写第二版时尤其如此：保留好用的结构（问句小标题、分条清单、场景化人群），只改说法，不要把清单压成一句话、把小标题拆掉。

带数字的框架很常用：5大问题、6大环节、8大模块、三步装好。数字让东西显得多、显得有体系。

### 结尾：交付 + 不退（4 条样例全都有）

```
拍下秒发度盘发 / 下单后系统自动发货提取内容，无需等待。
虚拟商品，售出不退不换，介意勿拍！
```
- 不退的理由可以带上，比如"因数字化资料具有可复制性"；也可以只写"不支持 7 天无理由退换"。
- 免责声明默认不加。只有一半样例有，而且对资料包来说，"侵权可删"反而在提醒买家"这是搬来的"，降低信任。用户要求时才加；自研工具可以用样例4那种显得专业的写法："本工具为原创整理，不替代你的〔判断〕，〔使用前〕请人工核对。"

## 三、语气：按商品类型切换

骨架相同，语气差别很大，按商品选：

| 类型 | 样例 | 长度 | 小标题 | 语气 |
|---|---|---|---|---|
| 资料包，解决家长/学生的焦虑 | 1 | 短 | 不用 | 痛点、确定感强："专治""解决…问题" |
| 资料包，打包卖给从业者 | 2 | 短 | 不用 | 口语、感叹号、可带 ✅ ⚠️，"低价白菜，知识无价～" |
| 资料包，买家就是用的人（学生、考生、年轻人） | 认可成品 | 中等 | 可用问句或分组小标题 | 贴近买家自己的说法（i人、二战、在职党），重点在场景化人群和打消顾虑，少喊口号 |
| 工具/软件/Skill | 3、4 | 长 | 【核心优势】式或"是什么？"问句式 | 说明书式，专业、克制，少用感叹号和 emoji |

工具越复杂，写得越长、分区越细，因为买家要先确认"我能不能用"：环境、系统、依赖、要不要 Key，都写进"使用须知"。

## 四、几个容易写走样的地方

- **用付钱人的词。** 学生资料的付钱人是家长，所以写"厌学、丢分、跟不上"，不写知识点。
- **并列词要短。** "叛逆、厌学、难沟通""智能粗剪 | 自动字幕 | 视觉设计"这种短词才干脆。写成"背了就忘""1600词记不牢"这种短句，就会拖沓。
- **同一组关键词在不同块里呼应。** 标题、开头、清单里用同样的核心词，既是给搜索加权，也是在加深印象。但在同一块里别反复堆同一个词，那是堆砌，不是呼应。
- **只写资料能证明的。** 集数、容量、页数、数量都从文件名或用户给的信息里取。不知道内容就停在文件名这一层，不编章节、不编效果、不编销量，编出来的东西会变成售后纠纷。
- **"适合谁"写场景，不写标签。** "一开口就紧张的社恐""聚会总冷场、不知道怎么接话的人"，买家一看就对号入座；"适合社恐、i人、新人"只是一串标签，没有画面。
- **只写买家关心的。** 不讲情怀，不讲来历，也不加营销分析，更不要教买家"先看哪个、再看哪个"，那是拿到货以后的事。

## 交付前扫一眼

不是打分表，只是几处最容易漏的地方：
- 标题：核心词在前 10 个字里吗？有没有同一个词出现两次？
- 年份：资料里真有这个年份吗？还在时效内吗？
- 内容：每个数字和说法，文件名或用户给的信息里都找得到吗？
- 店铺：和 `shop-log.md` 里最近几条撞脸了吗？写完记得追加一行。
- 底线：没有站外联系方式和私下交易的说法吧？

## 输出格式

1. **标题**：给 1 个主推，再给 2 个备选（换一组关键词，覆盖更多搜索）。
2. **正文**：放在一个代码块里，直接可以粘贴。
3. **提示**：只在需要时写一两行，见下一节。

## 合规提示

有一条底线，任何时候都不写进文案：站外联系方式和私下交易，比如"加微信/VX/QQ""扫码进群""私聊发完整版""走支付宝"。闲鱼对引流到站外零容忍，轻则下架，重则封号。交付写成"拍下后闲鱼内发网盘链接"这类说法就行。

标题里也要少用这几类词，它们在闲鱼属于高危或机器容易拦截的词：
- "白菜价""亏本""跳楼价"会被判虚假促销。放在正文语境里（如"低价白菜，知识无价"）问题不大。
- "神器""爆款""必备"这类营销词，标题里最多留一个。

动笔前，先用「闲鱼虚拟商品版权雷达」查一遍商品名、作者、讲师、机构和资料里的品牌词：https://yhslgg-arch.github.io/xianyu-blacklist/ 。它收录了 4000 多条闲鱼虚拟商品的投诉、售假、禁售记录，谐音和拆写也能认出来。命中了，就在提示里告诉用户命中的词和标签（比如"禁售类、封建迷信类""售假维权警告"），并且文案里不写这些词；没命中也不代表安全，它只是网络收集的线索，不是官方名单。2026-11-14 实测命中过：易经（禁售类、封建迷信类）、风水（禁售类）、学而思、叽里呱啦、粉笔、上岸熊、卢姨、冯唐、樊登、牛津分级阅读。

有些词闲鱼搜索直接搜不出结果。2026-11-14 实测，"风水"两次搜索都是零结果，而"易经""六爻资料""紫微斗数资料"都正常。这类词放进标题，买家搜不到，还可能让链接被审核盯上。先换成能搜到的近义词（易经、周易、国学、命理），并提醒用户上架后自己搜一下标题里的核心词。

其余情况照常写，但在"提示"里用一两行告诉用户风险，并给出替换写法，由用户决定：
- 涉及疾病或心理健康（抑郁、焦虑、失眠等），用了"专治、治愈"：可能被判违规宣传，建议改成"应对、了解"。
- 考试、投资类用了"包过、稳赚"，或者用了"最、第一、全网最全"这类绝对化用语。
- 明显是转卖别人的付费课程或已出版图书："侵权可删"挡不住投诉，有下架风险。标题和正文里尽量不写品牌名、机构名、讲师名、书名，这些是版权投诉和机器审核的主要命中点。
- 资料带有"破解版、永久激活、电子书PDF"这类字眼：这些属于闲鱼的盗版违规词，换成"安装包""电子版"等中性说法。

### 怎么用这些参考

- 样例1–4 有真实销量，是"市场验证过的写法"；认可成品是用户的口味，还没上架验证。两者冲突时，以样例和本文件的规则为准。
- 读认可成品时，先看文件里的"从这条学什么""别照抄什么"。学的是手法（场景化人群、三连否定、赠品分层），不是它的格式和句子。如果照着它的小标题结构写，整个店会变成一个样子，反而被判重复铺货。

### 维护参考库（用户说某条成品好、要存进来时）

- 每存一条，都写上"从这条学什么""别照抄什么"，并逐项对照本文件的规则，把不符合的地方标出来。
- 每种类型（资料包、工具）最多留 2 条认可成品。新的更好就替换旧的，不要无限累积，否则范例的吸引力会盖过规则。
- 留一行"真实数据"。上架后用户给出想要数、浏览、成交，就补上；有数据的优先保留。
